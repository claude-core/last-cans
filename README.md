# Last Cans

A single-player post-apocalyptic extraction game for iPhone Safari. Go topside,
scavenge pre-collapse hard seltzer cans, and get back to the lift before the
storm rolls in. Same zone for everyone each day, one official run, share your haul.

Plain HTML/CSS/JS + canvas. No build step. Open `index.html` or serve the folder.

Debug: `?zone=N` plays any zone without saving results (phase 3+).
